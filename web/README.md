# RoadService Web (React + Vite)

Thin FastAPI consumer for Government, Admin, and Contractor dashboards.

```bash
cp .env.example .env
npm install
npm run dev
```

- Dashboard with status donut + contractor bar charts
- Issues table with status pills + detail side panel
- Leaflet map with status-colored pins
- Excel / PDF export
- Admin user & project management

Surveyor login is blocked here (mobile-only).
