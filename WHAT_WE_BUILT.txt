RoadService – What we added (simple summary)
===========================================

Updated: August 2026

This note explains the upgrades in plain language (no technical jargon).


Earlier upgrades (still included)
---------------------------------
- Light / Dark mode
- Billing module (Contractor → Admin recommend → Government approve)
- Basic documents upload
- Vendor profiles
- Rates / BOQ, issues, notifications, mobile field app


New portal modules (from Portal Requirement)
--------------------------------------------

1) Full Document & Approval
- Version history for documents
- Check-in / Check-out
- Request approval / Approve / Reject
- Digital signature text on approval
- Watermark text + document classification
- Download activity logging

2) Attendance & Manpower
- Personnel register
- Daily attendance with GPS and biometric flag
- Leave requests and approval
- Duty roster support
- Today’s present / pending leave summary

3) Security & Access
- MFA PIN (optional second step at login)
- Login history
- Audit trail of important actions
- Security posture notes (encryption / SSO / WAF placeholders for enterprise setup)

4) Toll Operations
- Toll plaza master (lanes, ETC, tariff notes)
- Daily traffic, FASTag %, cash %, revenue, lane availability
- Toll KPI cards

5) Incident Management & Route Ops
- Highway incidents (accident / breakdown / fire / medical / security)
- 1033 source flag
- Respond and clear workflow
- Response vehicles list
- Active / cleared KPIs

6) ATMS / TMS / MLFF / ITS monitoring
- Device / node register by system type
- Online / degraded / offline status and health %
- Last heartbeat time

7) Civil Asset Inventory
- Bridges, pavement, culverts, furniture, etc.
- Chainage and condition
- Map coordinates (lat/lng) for GIS-ready view

8) Integrations register
- NHAI CCC, ERP, e-Office, Data Lake, Rajmarg Yatra, 1033, IHMCL
- Status and “Sync now” for demo connectivity tracking

9) Backup / DR / BCP
- Backup job schedule (incremental / full, onsite / offsite)
- Run / test backup action
- Business continuity checklist items

10) Executive NHIT Summary
- Stretch snapshot (length, progress, planned vs actual spend)
- Combined view of toll + incidents + ITS health
- Admin button: “Load demo NHIT data” to fill sample records


How to try it
-------------
1. Start backend and web app
2. Login:
   - admin@roadservice.app / Admin123!
   - contractor@roadservice.app / Contractor123!
   - gov@roadservice.app / Gov123!
3. As Admin open Executive → click “Load demo NHIT data”
4. Browse new menu items: Executive, Documents, Attendance, Toll Ops,
   Incidents, ATMS/TMS/ITS, Civil Assets, Integrations, Backup/DR, Security


Important honesty note
----------------------
These modules are built as a working portal inside RoadService.
They cover the requirement areas with real screens and workflows.
Full live connection to real NHAI CCC / ERP / WAF / biometric devices /
production SSO still needs organisation credentials and infrastructure
outside this demo app.


Next possible upgrades (later)
------------------------------
- Live SSO (Azure AD / NIC) and hardware MFA tokens
- Real plaza TMS feeds and ATMS video walls
- Full GIS map layers for assets and incidents
- Production backup agents and DR automation
